# CHANGELOG

## 2026-10-25 — 1.2.1

- Исправлено: через прокси Яндекс отвечал 404 и кнопки писали «Проверьте ключ Яндекса», хотя ключ был верный. Причина — заголовок `Host: api.weather.yandex.ru:80` в запросе через туннель; теперь `Host` задаётся явно.
- Из запроса к Яндексу убраны поля, закрытые для бесплатного ключа (`humidity`, `precProbability` → «access denied for free role»). Для Яндекса кнопка показывает порывы ветра вместо влажности и погоду днём вместо вероятности осадков.
- Ошибкой ключа считаются только HTTP 401/403; в лог пишется каждый запрос к Яндексу с числом городов.

## 2026-10-25 — 1.2.0

- Яндекс Погода: все кнопки (например, Уфа, Питер, Минск) запрашиваются **одним** GraphQL-запросом с алиасами `p0`, `p1`, `p2` вместо отдельного запроса на каждый город. Остальные кнопки перерисовываются из кэша, их таймеры выравниваются по общему запросу.
- Под лимит ключа (30 запросов в сутки, 1000 в месяц): обновление Яндекса не чаще раза в час (24 в сутки, ~744 в месяц), ручное обновление — не чаще раза в 15 минут, повтор после ошибки — через 30 минут.
- Ключ Яндекса теперь общий для всех кнопок (глобальные настройки плагина), а не вводится на каждой кнопке.
- Код Яндекса вынесен в `bin/yandex.js`.

## 2026-10-25 — 1.1.0

- Добавлен второй источник погоды — Яндекс Погода (GraphQL API с бесплатным ключом для умного дома, как в интеграции yandex/pogoda-home-assistant). Источник выбирается в настройках кнопки, там же вводится ключ.
- Для Яндекса обновление не чаще раза в 30 минут (у ключа суточный лимит), понятная ошибка при неверном или отсутствующем ключе.
- `http.js` научился POST-запросам с JSON-телом (нужно для GraphQL).

## 2026-10-25 — 1.0.0

- Создан плагин Stream Deck «Погода Open-Meteo»: действие «Погода» показывает текущую погоду с open-meteo.com.
- Три вида кнопки (сейчас / сегодня макс-мин и осадки / ветер и влажность), переключение коротким нажатием, долгое нажатие — обновить.
- Окно настроек: поиск города через геокодер Open-Meteo, координаты, °C/°F, м/с / км/ч, интервал обновления, подпись.
- Поддержка HTTP-прокси (системный прокси Windows подхватывается автоматически), т.к. встроенный Node.js Stream Deck его не использует, а api.open-meteo.com в сети пользователя напрямую недоступен.
- `Software.MinimumVersion` = 7.1 — этого требует `@elgato/streamdeck` 3.x (на 6.6 плагин падал при запуске).
- Скрипты: `scripts/install.ps1` (установка копированием — junction на диск S: Stream Deck не читает), `scripts/gen-icons.mjs` (генерация PNG-иконок).
