# CHANGELOG

## 2026-10-25 — 1.5.0

- Поддержка SOCKS-прокси: `socks5h://` (DNS через прокси), `socks5://`, `socks4a://`, `socks4://`, с логином и паролем. Раньше работал только HTTP-прокси, а SOCKS из системных настроек Windows игнорировался.
- Системный SOCKS-прокси Windows (`socks=` в настройках) используется как `socks5h`, если HTTP-прокси не задан; учитывается переменная `ALL_PROXY`.
- Ошибки прокси стали понятнее: в сообщении тип и адрес прокси и причина (отказ в соединении, неверный пароль, «это не SOCKS5-прокси» и т.п.).
- Подсказка с примерами адресов в окне настроек и таблица в README.
- Проверка прокси: кнопка «Проверить» рядом с полем «Прокси» (и автоматически при изменении поля). Плагин открывает через прокси защищённое соединение с сервером погоды выбранного источника и показывает «✓ Работает через …: N мс» или причину ошибки. Запрос погоды не отправляется — лимит Яндекса не тратится.
- Прокси стал общим для всех кнопок, как ключ Яндекса: поле «Прокси (общий)» на любой кнопке меняет его сразу для всех. Прокси, заданный раньше на отдельной кнопке, переносится в общие настройки автоматически. Запросы Яндекса объединяются только по ключу — разные прокси на кнопках больше не дают второй запрос (было 2 запроса в час вместо 1).
- Пароль прокси не попадает в лог и в окно настроек (`maskProxy()` заменяет его на `***`).

- Новый README: что это, картинка кнопок, возможности, установка, настройка Яндекса и подписи, частые вопросы, краткое описание на английском.
- Лицензия MIT, картинка `docs/preview.png` (скрипт `scripts/gen-preview.mjs`), сборка релиза `scripts/pack.ps1`.
- В манифесте: подробное описание, ссылка на репозиторий, автор Silence02ru.
- Автоматические релизы: GitHub Actions по тегу `v*` собирает `.streamDeckPlugin` и публикует его на странице Releases — ссылка «Скачать» в README теперь ведёт на настоящий файл.
- `manifest.json` переформатирован утилитой `@elgato/cli` при сборке, в `package-lock.json` обновлено имя пакета.

## 2026-10-25 — 1.3.0

- Название города на кнопке стало жирным и крупнее (24 px вместо 17) и само уменьшается под ширину кнопки — «Санкт-Петербург» больше не обрезается. Ширина рассчитывается по замеренным ширинам букв.
- Подпись привязана к настройкам Title в Stream Deck: текст Title заменяет название города (например, «Питер»), а при «Шрифт подписи → Из настроек Title» берутся шрифт, размер, стиль и цвет оттуда.
- Название города теперь показывается и в виде «Сегодня» (вместо слова «Сегодня») — чтобы различать кнопки разных городов.

## 2026-10-25 — 1.2.1

- Исправлено: через прокси Яндекс отвечал 404 и кнопки писали «Проверьте ключ Яндекса», хотя ключ был верный. Причина — заголовок `Host: api.weather.yandex.ru:80` в запросе через туннель; теперь `Host` задаётся явно.
- Из запроса к Яндексу убраны поля, закрытые для бесплатного ключа (`humidity`, `precProbability` → «access denied for free role»). Для Яндекса кнопка показывает порывы ветра вместо влажности и погоду днём вместо вероятности осадков.
- Ошибкой ключа считаются только HTTP 401/403; в лог пишется каждый запрос к Яндексу с числом городов.

## 2026-10-25 — 1.2.0

- Яндекс Погода: все кнопки (например, Уфа, Питер, Минск) запрашиваются **одним** GraphQL-запросом с алиасами `p0`, `p1`, `p2` вместо отдельного запроса на каждый город. Остальные кнопки перерисовываются из кэша, их таймеры выравниваются по общему запросу.
- Под лимит ключа (30 запросов в сутки, 1000 в месяц): обновление Яндекса не чаще раза в час (24 в сутки, ~744 в месяц), ручное обновление — не чаще раза в 15 минут, повтор после ошибки — через 30 минут.
- Ключ Яндекса теперь общий для всех кнопок (глобальные настройки плагина), а не вводится на каждой кнопке.
- Код Яндекса вынесен в `bin/yandex.js`.

## 2026-10-25 — 1.1.0

- Добавлен второй источник погоды — Яндекс Погода (GraphQL API с бесплатным ключом для умного дома, как в интеграции yandex/pogoda-home-assistant). Источник выбирается в настройках кнопки, там же вводится ключ.
- Для Яндекса обновление не чаще раза в 30 минут (у ключа суточный лимит), понятная ошибка при неверном или отсутствующем ключе.
- `http.js` научился POST-запросам с JSON-телом (нужно для GraphQL).

## 2026-10-25 — 1.0.0

- Создан плагин Stream Deck «Погода Open-Meteo»: действие «Погода» показывает текущую погоду с open-meteo.com.
- Три вида кнопки (сейчас / сегодня макс-мин и осадки / ветер и влажность), переключение коротким нажатием, долгое нажатие — обновить.
- Окно настроек: поиск города через геокодер Open-Meteo, координаты, °C/°F, м/с / км/ч, интервал обновления, подпись.
- Поддержка HTTP-прокси (системный прокси Windows подхватывается автоматически), т.к. встроенный Node.js Stream Deck его не использует, а api.open-meteo.com в сети пользователя напрямую недоступен.
- `Software.MinimumVersion` = 7.1 — этого требует `@elgato/streamdeck` 3.x (на 6.6 плагин падал при запуске).
- Скрипты: `scripts/install.ps1` (установка копированием — junction на диск S: Stream Deck не читает), `scripts/gen-icons.mjs` (генерация PNG-иконок).
