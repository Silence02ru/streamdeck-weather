# Погода Open-Meteo для Stream Deck

Кнопка Stream Deck с актуальной погодой с [open-meteo.com](https://open-meteo.com) (бесплатно, без ключа)
или [Яндекс Погоды](https://yandex.ru/pogoda/b2b/smarthome) (бесплатный ключ).

## Установка

Нужны Stream Deck 7.1+ и Node.js/npm (для установки зависимостей).

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

Скрипт поставит зависимости, скопирует плагин в папку Stream Deck и перезапустит приложение.

## Использование

1. Перетащите действие **Погода** (категория «Погода») на кнопку.
2. В настройках введите город и нажмите «Найти» — или укажите координаты.
3. Короткое нажатие кнопки переключает вид: **сейчас** → **сегодня** (макс/мин, осадки) → **ветер и влажность**.
   Долгое нажатие — обновить немедленно.

### Яндекс Погода

В настройках выберите источник **Яндекс Погода** и вставьте ключ. Бесплатный ключ выдаётся на
[yandex.ru/pogoda/b2b/smarthome](https://yandex.ru/pogoda/b2b/smarthome), активируется до 5 минут.
Из-за лимита запросов у ключа погода с Яндекса обновляется не чаще раза в 30 минут.

Если интернет идёт через прокси, плагин сам возьмёт системный прокси Windows. Можно указать вручную (`host:port`) или `none`.
